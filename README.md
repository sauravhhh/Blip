# Blip

Offline Bluetooth text chat between two phones. No internet, no accounts, no servers.

## How to use

1. Install the APK on **both** phones.
2. Turn on Bluetooth on both.
3. One phone taps **Host** (becomes visible for 5 minutes).
4. The other phone taps **Scan**, then taps the first phone in the device list.
5. Type and send — messages go straight over Bluetooth.

## Details

- Package: `com.sauravhhh.blip`
- Min Android 8.0 (API 26), targets Android 14
- Uses Bluetooth Classic (RFCOMM) — works fully offline
- ~21 KB
